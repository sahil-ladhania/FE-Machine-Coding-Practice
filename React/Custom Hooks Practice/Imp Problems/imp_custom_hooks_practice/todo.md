# Custom Hooks Practice

---

## 1. useDebounce
- Input field jisme user type kare
- Debounced value console mein print ho after delay

---

## 2. useFetch
- Hardcode ek public API URL (e.g. jsonplaceholder)
- data, loading, error console ya simple text mein dikhao

---

## 3. usePrevious
- Counter with +/- buttons
- Current aur previous value dikhao

---

## 4. useLocalStorage
- Input field jo localStorage mein save ho
- Page reload ke baad bhi value wapas aaye

---

## 5. useToggle
- Ek button jo true/false toggle kare
- Current value dikhao

---

## 6. useThrottle
- Input field jisme har keystroke pe value throttle ho
- Throttled value console mein print ho

---

## 7. useClickOutside
- Ek div/box banao
- Jab bahar click karo toh console mein "clicked outside" print ho

---

## 8. useWindowSize
- Width aur height dikhao on screen
- Resize karne pe update ho

---

## 9. useInterval / useTimeout
- useInterval: counter jo har 1s pe increment ho, start/stop button
- useTimeout: button click pe 2s baad ek message dikhao

---

## 10. useAsync
- Ek button jo async function trigger kare (fake API call with setTimeout)
- loading, data, error states dikhao
